I’ve tried lots of coding agents, such as Claude Code, Codex, Pi and OpenCode, but I keep coming back to OpenCode. The flexible configuration, keyboard shortcuts, and visual presentation in a terminal really appeal to me. However, I run into situations where certain sets of models and agents make sense in one software project but not another.
